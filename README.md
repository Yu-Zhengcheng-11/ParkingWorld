# ParkingWorld Project Page

Static GitHub Pages site for:

**ParkingWorld: End-to-End Autonomous Parking Reinforcement Learning from Human Experience in 3DGS Simulation**

Deploy this folder as the `ParkingWorld` repository or copy its contents into the GitHub Pages source for:

`https://Yu-Zhengcheng-11.github.io/ParkingWorld/`

## Local preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

from this directory and visit `http://localhost:8000`.
